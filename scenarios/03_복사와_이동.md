# 실습 3단계 — 파일 복사와 이동

## 학습 목표

`cp`와 `mv`로 파일과 폴더를 복사 · 이동하고 이름을 바꿀 수 있습니다. 와일드카드로 여러 파일을 한 번에 다룰 수 있습니다.

---

## 배경 시나리오

> 배포 전에 서버 설정 파일을 백업해야 합니다.
> 다운로드 폴더에는 표지 이미지와 주문서가 뒤섞여 있어서 정리도 필요합니다.
> `cp`로 백업을 만들고 `mv`로 파일을 정리해 봅시다.

---

## 명령어 요약

| 명령어 | 설명 | 기본 형식 |
| --- | --- | --- |
| `cp` | 복사 (원본은 남음) | `cp [옵션] 원본 대상` |
| `mv` | 이동 · 이름 변경 (원본은 사라짐) | `mv [옵션] 원본 대상` |

| 옵션 · 기호 | 설명 |
| --- | --- |
| `cp -r` | 폴더 전체 복사 (recursive) |
| `cp -i` / `mv -i` | 덮어쓰기 전에 확인 (interactive) |
| `cp -v` | 무엇을 어디로 복사했는지 출력 (verbose) |
| `*.txt` | 이름이 `.txt`로 끝나는 모든 파일 (와일드카드) |
| `*.{html,css}` | html 파일과 css 파일 |

> 💡 순서는 항상 **원본 → 대상**입니다. 대상 자리에 같은 이름의 파일이 있으면 **묻지 않고 덮어씁니다.**

---

## 실습 문제

### 준비

```bash
cd ~/Desktop/unix-command/practice
mkdir backup
```

---

### 문제 1 — 설정 파일 백업하기

```bash
cp configs/server.conf backup/server.conf.bak
ls backup
```

---

### 문제 2 — 복사 과정 보면서 복사하기 (-v)

날짜를 붙인 백업을 하나 더 만듭니다.

```bash
cp -v configs/server.conf backup/server.conf.20261008
ls -l backup
```

---

### 문제 3 — 덮어쓰기 전에 확인하기 (-i)

```bash
cp -i configs/server.conf backup/server.conf.bak
# overwrite ... ? 라고 물으면 n을 입력하고 Enter (덮어쓰지 않음)
```

---

### 문제 4 — 폴더 통째로 복사하기 (-r)

```bash
cp website backup/        # 오류: 폴더는 -r이 있어야 복사됩니다
cp -r website backup/website_backup
ls -R backup
```

---

### 문제 5 — 와일드카드로 여러 파일 복사하기

```bash
mkdir backup/assets
cp website/css/*.css backup/assets/          # css 파일 전부
cp website/js/*.js website/index.html backup/assets/
cp downloads/*.{jpg,pdf} backup/assets/      # jpg 파일과 pdf 파일
ls backup/assets
```

> 💡 `*`는 아무 글자나 몇 개든 대신합니다. `{html,css}`처럼 중괄호를 쓰면 여러 확장자를 한 번에 적을 수 있습니다.

---

### 문제 6 — 이름 바꾸기 (mv)

```bash
mv backup/server.conf.bak backup/server.conf.old
ls backup
```

> 💡 대상이 **없는 이름**이면 이름이 바뀌고 **있는 폴더**면 그 폴더 안으로 옮겨집니다.

---

### 문제 7 — 다른 폴더로 옮기기 (mv)

```bash
mkdir archive
mv backup/server.conf.old archive/
ls backup
ls archive
```

---

### 문제 8 — 실전: 다운로드 폴더 정리하기

```bash
cd downloads
ls
mkdir images documents css
mv *.jpg images/
mv *.pdf documents/
mv *.css css/
ls
ls images documents css
cd ..
```

> 🔍 파일이 100개여도 명령어 수는 똑같습니다. 이것이 커맨드 라인이 빠른 이유입니다.

---

## 확인 질문

1. `cp`와 `mv`의 가장 큰 차이는 무엇일까요?
2. `mv old.txt new.txt`를 실행하면 어떻게 될까요?
3. 폴더를 복사할 때 꼭 필요한 옵션은 무엇일까요?

<details>
<summary>답 보기</summary>

1. `cp`는 원본이 남고 `mv`는 원본이 원래 자리에서 사라집니다.
2. `new.txt`라는 이름의 파일이 없으면 `old.txt`의 이름이 `new.txt`로 바뀝니다.
3. `-r`입니다. 없으면 폴더는 복사하지 않고 오류를 냅니다 (예: `-r not specified; omitting directory`).
</details>
