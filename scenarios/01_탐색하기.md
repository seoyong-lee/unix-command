# 실습 1단계 — 파일 시스템 탐색하기

## 학습 목표

`pwd`, `ls`, `cd`로 지금 위치를 확인하고 절대 경로와 상대 경로로 폴더 사이를 이동할 수 있습니다.

---

## 배경 시나리오

> 오늘 '숲속 책방' 웹팀에 새로 들어왔습니다.
> 선임 개발자가 프로젝트 폴더를 넘겨주었는데 터미널을 열어 보니 **지금 어디에 있는지도 모르겠습니다.**
> 폴더 구조부터 차근차근 파악해 봅시다.

---

## 명령어 요약

| 명령어 | 설명 | 기본 형식 |
| --- | --- | --- |
| `pwd` | 현재 위치(절대 경로) 출력 | `pwd` |
| `ls` | 폴더 안의 파일 · 폴더 목록 | `ls [옵션] [경로]` |
| `cd` | 다른 폴더로 이동 | `cd [경로]` |

| `ls` 옵션 | 설명 |
| --- | --- |
| `-l` | 상세 정보 (권한 · 소유자 · 크기 · 수정 시각) |
| `-a` | 숨김 파일(`.`으로 시작하는 파일)까지 모두 |
| `-al` | 두 옵션을 합쳐서 (순서는 상관없음) |

| `cd` 형태 | 이동하는 곳 |
| --- | --- |
| `cd 폴더명` | 하위 폴더 |
| `cd ..` / `cd ../..` | 한 단계 위 / 두 단계 위 |
| `cd` 또는 `cd ~` | 홈 디렉터리 |
| `cd -` | 바로 전에 있던 위치 |
| `cd /` | 루트 디렉터리 |

---

## 실습 문제

### 문제 1 — 내 위치 확인하기

터미널을 열자마자 지금 어디에 있는지 확인합니다.

```bash
pwd
```

> 💡 출력된 경로가 **현재 작업 디렉터리**입니다. 프롬프트의 `~`는 홈 디렉터리를 줄여 쓴 것입니다.

---

### 문제 2 — 실습 폴더로 이동하기

바탕화면의 `unix-command` 폴더 안 `practice` 폴더로 이동합니다.

```bash
cd ~/Desktop/unix-command
ls
cd practice
pwd
```

> 💡 폴더 이름은 앞 몇 글자만 치고 **Tab**을 누르면 자동으로 완성됩니다. `cd pra` + Tab → `cd practice/`

---

### 문제 3 — 폴더 내용 살펴보기

`practice` 폴더 안에 무엇이 있는지 옵션을 바꿔 가며 확인합니다.

```bash
ls
ls -l
ls -a
ls -al
```

> 🔍 `ls`에는 없던 `.env.example`이 `ls -a`에서는 보입니다. 이름이 `.`으로 시작하는 **숨김 파일**입니다.
> 🔍 `ls -l` 맨 앞 글자 `d`는 디렉터리, `-`는 일반 파일입니다.

---

### 문제 4 — website 폴더 탐색하기

`website` 폴더로 들어가서 안을 살펴봅니다.

```bash
cd website
ls -l
```

---

### 문제 5 — 위로 올라가고 되돌아오기

```bash
cd ..        # 한 단계 위 (practice)
pwd
cd -         # 바로 전 위치 (website)로 되돌아가기
cd ../..     # 두 단계 위 (unix-command)
pwd
cd practice
```

---

### 문제 6 — 절대 경로와 상대 경로

같은 폴더를 두 가지 방법으로 찾아가 봅니다.

```bash
# 상대 경로: 지금 위치(practice)에서 출발
cd website/css
pwd          # 출력된 경로를 복사해 둡니다

# 홈으로 한 번에 이동
cd

# 절대 경로: 루트(/)부터 적은 경로로 이동
cd 복사해둔경로
pwd

# ~를 쓰면 홈 디렉터리 아래 경로를 짧게 적을 수 있습니다
cd ~/Desktop/unix-command/practice
```

---

### 문제 7 — 이동하지 않고 다른 폴더 보기

`ls` 뒤에 경로를 적으면 그 폴더로 가지 않고도 내용을 볼 수 있습니다.

```bash
ls website
ls -l website/css
ls configs logs
```

## 확인 질문

1. `cd ~`를 입력한 뒤 `pwd`를 입력하면 어떤 경로가 나올까요?
2. `ls -l` 결과에서 파일 크기와 수정 시각은 어디에 나올까요?
3. 절대 경로와 상대 경로는 어떻게 구별할까요?
4. `cd -`는 어디로 이동할까요?

<details>
<summary>답 보기</summary>

1. 홈 디렉터리 경로입니다. Mac은 `/Users/사용자이름`, Windows Git Bash는 `/c/Users/사용자이름`입니다.
2. 소유자 · 그룹 다음 칸이 크기(바이트), 그다음이 수정 시각이고 맨 끝이 이름입니다.
3. `/`로 시작하면 루트부터 적은 절대 경로이고 그렇지 않으면 지금 위치에서 출발하는 상대 경로입니다.
4. 바로 전에 있던 위치로 돌아가고 그 경로를 출력합니다.
</details>
